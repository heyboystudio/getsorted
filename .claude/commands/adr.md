Record this decision: $ARGUMENTS

1. Read `docs/architecture/decisions.md` and `docs/templates/adr.md`.
2. Use the next free number. If the decision replaces an existing one, mark the old entry "Superseded by NNN" instead of editing its content.
3. Fill Context, Options considered (2–3), Decision, Consequences. For a new dependency include: maintainer activity, licence, compatibility with the installed Laravel/Filament/Livewire versions, and how we'd remove it.
4. Add the row to the summary table at the top.
5. Explain the decision to the founder in two or three plain sentences.
